# ELECTRO ERP 전기자재 카탈로그·가격비교 구현 기록

기준일: 2026-09-22

## 적용 원칙

- 기존 `catalog_products → supplier_products → price_history → 구매요청 → 발주 → 입고 → 재고` 흐름을 유지하고 확장했다.
- Product Master와 판매처 상품은 별도 테이블로 유지한다.
- 공식 API/Feed/카탈로그를 우선하며, 정책 확인 전 웹 수집은 실행하지 않는다.
- 불확실한 동일상품은 자동 확정하지 않고 관리자 검수 큐로 보낸다.
- 관리자가 확정한 마스터 필드는 `manual_fields`에 기록해 향후 동기화 덮어쓰기 방지 기준으로 사용한다.

## 구현된 범위

### 데이터 모델

- Product Master 공식정보: 브랜드, 세부분류, 시리즈, 모델, 제품코드, 공식 URL, 이미지, 데이터시트, 카탈로그, 인증, 소스, 동기화일
- Supplier Product 판매정보: 외부상품 ID, 원문/정규화 상품명, 제조사/모델, 원문/구조화 규격, 판매가/정가/VAT, 배송비/기타비용, MOQ, 재고, 납기, 확인일, 매칭 신뢰도
- Price History: 판매상품 ID, 가격, 배송비, 재고, VAT, 확인시각 스냅샷
- 동일상품 검수 큐 및 구매후보 테이블
- 외부 Source 정책상태, 등급, 최근 성공/오류, 다음 동기화 시각

### 분류·검색

- 제조사/판매처 구조를 반영한 상위 그룹–카테고리–세부분류 트리
- 케이블, 차단기, 전선관, 배선기구, 터미널, 제어기기, 조명, 접지, 배선부자재 등 카테고리별 규격 Schema
- 카테고리 선택에 따라 제조사와 규격 항목이 바뀌는 Dynamic Filter API/UI
- 모델·제품코드·제조사 표시와 공식정보 저장 구조

### 동일상품 매칭

1. 제조사 제품코드
2. 유일한 정확 모델번호
3. 제조사 정규화 + 모델번호
4. 카테고리 + 핵심 규격
5. 상품명 유사도는 검수 후보 제안에만 사용

매칭 근거와 `match_confidence`를 저장한다. 0.8 미만은 검수 큐로 보내며 관리자 승인, 다른 마스터로 재연결, 반려를 지원한다.

### 가격비교·구매 연결

- 가격, VAT, 배송비, 기타비용, MOQ를 포함한 첫 주문 예상금액
- 재고/납기/마지막 확인시간 및 3일 이상 경과 경고
- 판매처 구매사이트 이동 전 구매후보 기록
- 기존 견적함, 구매요청, 발주, 입고, 재고 흐름 재사용

### Source 안전장치

- 네이버 쇼핑 검색 Open API는 2026-07-31 종료 상태로 강제 비활성화했다.
- 일반 쇼핑몰 수집은 `policy_status=approved`가 아니면 실행하지 않는다.
- 관리자 연동 화면에서 Source 등급, 정책상태, 최근 성공/오류를 표시한다.
- 나라장터 종합쇼핑몰과 계약 공급처 REST 경로는 기존 Adapter를 재사용한다.

## 외부 협의가 있어야 활성화할 항목

- Schneider Product Catalog/Availability API 파트너 승인 및 자격증명
- LS ELECTRIC 카탈로그/제품 데이터 재사용·자동수집 허용 확인
- LS전선·대한전선 PDF 카탈로그의 DB 변환 및 이미지 재사용 범위 확인
- 각 판매처의 공식 Feed/API 제공 또는 자동수집 서면 허용

위 승인이 없는 Source는 운영 데이터 자동수집에 사용하지 않는다.
