## 다음에 할 일 (순서대로)

### 1. 수집기를 화면에서 돌릴 수 있게
지금은 터미널에서만 됩니다.

```bash
node backend/collect-prices.mjs --limit 30 --category breaker
```

**할 일**: `자재 > 자재 채우기` 화면에 "판매가 수집" 버튼을 만들고, 진행률과
결과(몇 건 찾고 몇 건이 규격 일치인지)를 보여 줍니다. 수집이 오래 걸리므로
백그라운드로 돌리고 상태를 폴링하는 구조가 필요합니다.

### 2. 수집 결과를 자동으로 적재
지금은 CSV로 떨어지고 사람이 다시 올려야 합니다.
**할 일**: 수집기가 로컬 API(`/api/catalog/import`)로 바로 밀어넣게 합니다.
판매처(몰)별로 공급처를 자동 생성하고, `price_basis`는 `retail`로 둡니다.

### 3. 쿠팡 말고 다른 몰도 잡기 ★ 가장 중요
**지금 상태**: 수집기가 **쿠팡만** 가져옵니다.

**확인된 사실** — 같은 페이지를 브라우저로 끝까지 내려 로고를 세어 보면
다른 몰도 분명히 있습니다:

```
쿠팡 15 · 옥션 16 · G마켓 13 · 11번가 7   (가격 표기 65개)
```

**원인**: 수집기의 블록 선택자가 첫 화면의 쿠팡 제휴 영역만 잡습니다.

```js
// backend/collect-prices.mjs 의 searchEnuri()
document.querySelectorAll("li[class*='item'], .prodItem, .item_box, li[data-goodsno]")
```

스크롤은 이미 넣었는데도 5건만 잡히므로, **본 목록의 DOM 구조를 다시 확인해
선택자를 고쳐야** 합니다.

**다음에 할 순서**:
1. 브라우저로 에누리 검색 페이지를 열고, `옥션 로고` 이미지의 **부모를 거슬러
   올라가며** 상품 카드 컨테이너의 class 를 찾습니다.
2. 그 선택자로 바꾸면 4개 몰이 한꺼번에 들어옵니다.
3. 다나와도 같은 방식으로 붙여 결과를 합칩니다 (robots 허용 확인됨).

## 확인된 사실 (다시 조사하지 말 것)

| 대상 | 결과 | 근거 |
|---|---|---|
| 쿠팡 직접 수집 | **불가** | `robots.txt` 조회 자체가 Access Denied |
| 네이버쇼핑 | **불가** | `robots.txt` = `Disallow: /`, 검색 API도 2026-07-31 종료 |
| 다나와 | **허용** | `/api/`·`/ajax/`만 차단, 검색·상품 허용. 목록은 JS 렌더 |
| 에누리 | **허용** | `Allow: /`. 목록은 JS 렌더. 끝까지 스크롤하면 쿠팡·옥션·G마켓·11번가 로고 51개 확인 |
| 전선조합 고시가 | **허용** | `/04.industry/` 열림 (`/04.members/`만 차단). HTML 표 |
| LS ELECTRIC | 제품 DB **없음** | `/ko/api/download.ashx`는 카탈로그 PDF 4,594건 목록뿐 |
| 나비엠알오 | 허용 | 상품 페이지에 가격이 HTML로 있음. 검색 URL은 추가 확인 필요 |
| 한국물가정보(KPI) | 유료 구독 | 업계 표준 단가지. API 여부 미확인 |

**원칙**: robots.txt가 막은 곳은 브라우저를 써도 안 됩니다. 도구 문제가 아니라
허락 문제입니다. 열어 둔 곳만 읽습니다.
