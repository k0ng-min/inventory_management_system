## 1단계 · 오늘 안에 (이거 안 하면 안 돌아감)

### 1. 사업장 만들기 ★ 가장 급함
`재고 > 기준정보 > 창고등록` 에서 **사업장 1개**를 만듭니다. 이름은 `본사 사업장`
같은 것으로 충분합니다.

> 지금 0개라서 입고·재고조정·자재배정이 전부 막혀 있습니다.
> 하나만 만들면 앞으로 화면이 창고를 묻지 않습니다. (두 개 이상 만들면 그때부터
> 창고 선택 칸과 재고이동 메뉴가 다시 나타납니다.)

### 2. 회사정보 채우기
`설정 > 회사정보` — 회사명 · **사업자번호** · 대표 · 주소 · 전화.

> 공급처에 보내는 **발주서에 그대로 찍힙니다.** 비어 있으면 발주서에 `-` 로 나갑니다.

### 3. 계정 정리
`설정 > 사용자·권한`

- 지금 역할: 설경민(관리자) · 정미라(구매담당) · 김현우/박지민(창고담당) · **이준호(조회전용)**
- 이준호 씨가 실제로 입고·재고 일을 한다면 **창고담당**으로 바꿔 주세요. 조회전용은 아무것도 못 씁니다.
- 각자 로그인해서 `설정 > 비밀번호 변경` 으로 바꾸게 하세요.

**권한 요약**

| 역할 | 할 수 있는 것 |
|---|---|
| 관리자(사장) | 전부 + 회계·입찰·분석 + 사용자·연동·회사정보 |
| 구매담당 / 창고담당 | 재고·구매·영업·공사·일정 전부, 금액도 전부 보임 |
| 조회전용 | 보기만 |

## 2단계 · 기준정보 채우기 (이 순서대로)

### 4. 거래처 명부 올리기
`구매 > 기준정보 > 거래처 일괄 등록`

엑셀 명부를 **`다른 이름으로 저장 → CSV(쉼표로 분리)`** 한 뒤 올립니다.
첫 줄이 머리글이어야 하고, 아래 이름들은 알아서 찾습니다.

```
업체명, 사업자번호, 담당자, 전화, 이메일, 결제조건, 비고
```

- 공급처 · 고객을 따로 올립니다(화면 위 칩으로 전환).
- 이미 있는 업체는 **빈 칸만 채우고 들어 있던 값은 덮어쓰지 않습니다.**
- 올리기 전에 미리보기로 무엇이 새로 들어가는지 먼저 보여 줍니다.

### 5. 공사(현장) 등록
`공사 > 공사등록` — 진행 중인 현장을 넣습니다.
구매요청할 때 **어느 공사 자재인지** 골라야 하고, 공사별 원가가 여기서 집계됩니다.

### 6. 공급처 품목·단가 올리기 ★ 가격비교의 재료
`구매 > 기준정보 > 공급처 품목 등록`

지금 판매처 단가가 **20건뿐**이라 비교할 것이 거의 없습니다. 거래하는 업체의
단가표를 CSV 로 받아 업체마다 한 번씩 올려 주세요.

```
품명, 단위, 단가, 배송비, 최소수량, 납기, 재고
CV 2.5SQ 4C 0.6/1kV, 100m, 118000, 20000, 1, 3일, 12
```

- **품명만 있어도** 올라갑니다(단가 없는 품목만 채우기).
- 업체마다 이름을 다르게 적어도 규격이 같으면 한 제품으로 묶입니다.
  (`CV2.5 4C` = `CV 2.5SQ 4C` = `CV 2.5㎟ 4C`)
- 같은 업체 단가표를 다시 올리면 **가격 이력이 쌓입니다** — 이게 나중에
  "지난번보다 올랐나" 를 답해 줍니다.

### 7. 규격 검수 큐 비우기
`구매 > 기준정보 > 규격 검수`

파서가 규격을 반만 읽은 제품이 모입니다. 분류를 고르고 규격을 채워 **확정**하면
같은 제품끼리 제대로 묶입니다. 안 쓰는 제품은 `사용안함` 으로 숨깁니다.

> 여기를 안 비우면 같은 물건이 두 줄로 남아 가격비교가 어긋납니다.

## 3단계 · 재고 기초 잡기

### 8. 사내 품목 만들기
`재고 > 기준정보 > 품목 마스터` 에서 확인하고, 없으면 `기준정보 > 품목등록`.

> 통합검색에서 **구매요청을 넣으면 사내 품목이 자동으로 만들어집니다.**
> 그래서 실제로는 8번을 건너뛰고 10번(한 건 돌려보기)부터 해도 됩니다.
> 다만 **지금 창고에 이미 있는 자재**는 아래 9번으로 직접 넣어야 합니다.

### 9. 기초재고 입력
`재고 > 재고조정` — 품목을 고르고 **실제 수량**을 적습니다. 사유는 `기초재고 이관`.

### 10. 최소(안전)재고 설정
`재고 > 기준정보 > 품목등록` 에서 품목마다 **안전재고**를 넣습니다.

> 이 값이 있어야 홈의 **부족 자재** 와 재고현황의 `부족` 표시가 동작합니다.
> 안 넣으면 0 이라 영원히 "정상" 으로 나옵니다.

## 4단계 · 한 건 끝까지 돌려보기

실제 구매 한 건을 처음부터 끝까지 해 보세요. 중간에 막히는 곳이 있으면 그게
진짜 고쳐야 할 곳입니다.

```
홈 '오늘 할 일' 검색창에 "CV 2.5 4C"
   ↓
검색 결과에서 제품 두어 개 체크 → 비교하기        (규격·가격·납기·과거 구매가)
   ↓
견적함에 담기 → 견적 비교                          (한 곳 몰아주기 vs 쪼개 사기)
   ↓
구매요청 → 승인 → 발주서                           (여러 품목이면 한 장으로 묶임)
   ↓
발주서 행에서 '인쇄' → 공급처에 보냄
   ↓
물건 도착하면 입고처리 (품목마다 수량, 불량 있으면 불량 칸에)
   ↓
재고현황에서 늘어난 것 확인
```

한 바퀴 돌고 나면 그 제품의 **지난 구매가**가 남습니다. 다음에 같은 걸 검색하면
`지난 구매 1,280원 · −40원 −3.1%` 처럼 바로 보입니다. 이게 이 시스템의 핵심입니다.

## 6단계 · 상시 운영

### 11. 서버 켜 두기
지금은 이 PC에서 제가 띄워 둔 상태입니다. 껐다 켜면 사라집니다.

```bash
npm start        # http://127.0.0.1:4173
```

항상 쓰려면 **한 대를 서버로 정해** 놓고 부팅 시 자동 실행되게 하세요
(작업 스케줄러 → 로그온 시 `npm start`).

### 12. 다른 PC·휴대폰에서 접속하려면
지금은 `127.0.0.1` 이라 **그 PC에서만** 열립니다. 사내에서 같이 쓰려면:

```bash
HOST=0.0.0.0 npm start
```

그리고 Windows 방화벽에서 4173 포트를 열어 주세요. 접속 주소는
`http://서버PC의사내IP:4173` 입니다.

### 13. 백업 ★ 꼭
모든 데이터가 **파일 하나**에 들어 있습니다.

```
backend/erp.db          ← 이것과
backend/erp.db-wal      ← 이것을 같이 복사
```

서버를 끈 상태에서 두 파일을 통째로 복사해 두면 그게 백업입니다.
일주일에 한 번, USB 나 클라우드에 넣어 두세요.

## 알아 두실 제약

- **서버를 다시 켜면 전원 로그아웃됩니다.** 세션이 메모리에 있어서입니다.
- **엑셀(.xlsx)은 직접 못 올립니다.** 엑셀에서 `CSV로 저장` 한 뒤 올리세요.
- 쿠팡·알리 연동은 키가 없어 실제 응답으로 검증하지 못했습니다. 키를 넣으면
  `연동설정` 의 `probe` 로 필드부터 확인해야 합니다.
- 발주서는 **인쇄(PDF 저장)** 까지 됩니다. 메일 자동 발송은 없습니다.
