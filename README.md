# 재고관리시스템

전기공사 회사용 **자재 구매 · 재고 · 공사 · 회계 통합 ERP**.
업무용 화면 구조(상단 모듈 네비 · 좌측 트리메뉴 · 멀티탭 · 밀도 높은 그리드) 위에
실측 기반 디자인 시스템을 입혔고, **나라장터(조달청) 입찰공고**를 날짜별로 조회합니다.

외부 의존성 0개 — Node 22 내장 모듈(`node:http`, `node:sqlite`)과 바닐라 JS만 사용합니다.

## 디자인

수치를 감으로 정하지 않고, 현재 가장 널리 복제되는 UI 세 곳의 실제 computed style 을 측정해 맞췄습니다.

| 항목 | shadcn/ui | Tremor | Linear | **이 시스템** |
|---|---|---|---|---|
| 표 셀 | 14px / 400 | 14px / 400 | — | **14px / 400** |
| 표 헤더 | 14px / 500 | 14px / 600 | — | **14px / 600** |
| 행 높이 | 49px | 54px | — | **48px** |
| 자간 | normal | normal | 큰 제목만 음수 | **normal** |
| 카드 라운드 | 10px | 10px | — | **12px** |
| 카드 그림자 | 없음 | 없음 | 없음 | **없음 (1px 테두리)** |

측정에서 얻은 원칙 세 가지를 그대로 적용했습니다.

1. **작게 쓰지 않는다.** 본문·표 모두 14px. 이전 버전의 12.5px 표와 10px 대문자 라벨은 전부 폐기했습니다.
2. **자간을 건드리지 않는다.** Pretendard 는 자간이 이미 최적화되어 있어, 전역 음수 자간은 오히려 한글을 뭉치게 만듭니다. 24px 이상 제목에만 `-0.02em` 을 씁니다.
3. **그림자 대신 테두리.** 면 구분은 1px `--line` 으로만 하고, 그림자는 모달에만 씁니다.

### 팔레트

| 요소 | 값 |
|---|---|
| 캔버스 | `#f6f8fb` · 카드 `#ffffff` · 보조면 `#f8fafc` / `#f1f5f9` |
| 본문 | `#0f172a` · 보조 `#475569` · 흐림 `#8894a8` (모두 4.5:1 이상) |
| 액센트 | 블루 `#2563eb` — **버튼과 현재 위치에만** 씁니다 |
| 상태 | 정상 `#15803d` · 주의 `#b45309` · 위험 `#dc2626` |

액센트 파랑과 상태 초록을 분리한 이유: 둘 다 파랑이면 "누를 수 있는 것"과 "상태가 좋은 것"이 구분되지 않습니다.

### 서체

Pretendard 하나로 한글·영문·숫자를 모두 처리합니다. 이전에는 라틴이 Space Grotesk,
한글이 맑은 고딕으로 갈려 한 줄 안에서 서체가 바뀌었습니다.
숫자는 전부 `tabular-nums` 라서 표에서 자릿수가 흔들리지 않습니다.
CDN 이 막힌 환경에서는 시스템 폰트로 자연스럽게 대체됩니다.

### 레이아웃

- 좌측 메뉴 **252px** (업계 관행 240~280px)
- 대시보드는 **KPI 6장 한 줄 + 콘텐츠 그리드** — 현행 대시보드의 표준 골격
- 열이 많은 그리드는 가로 스크롤을 허용하되, **업무 버튼 열을 오른쪽에 고정**해 스크롤 위치와 무관하게 조작 가능
- 긴 텍스트 열은 말줄임 처리해 표가 화면을 넘지 않게 합니다

### 입력 컨트롤

`<select>` · `<input type=date>` · 숫자 스피너는 OS 마다 모양이 달라 화면 톤을 깨뜨리므로
`controls.js` 에서 직접 만들어 씁니다.

- **콤보박스** — 항목이 8개를 넘으면 검색창이 붙고, ↑↓ Enter Esc 로 조작합니다
- **날짜 선택** — 월 달력 팝오버, 오늘·지우기 버튼
- **금액 입력** — 입력 중에도 천단위 구분을 유지하고, 제출할 때는 순수 숫자만 보냅니다

세 컨트롤 모두 `.value` 게터·세터와 `.focus()` 를 노출해 폼 엔진에서 `<input>` 과 똑같이 다뤄집니다.
`<dialog>` 는 최상위 레이어라, 모달 안에서 열린 팝오버는 body 가 아니라 그 dialog 에 붙입니다.

CSS 토큰은 `--accent*`, `--surface*`, `--fg*` 세 계열뿐이라
`styles.css` 최상단 `:root` 만 바꾸면 팔레트 전체가 교체됩니다.
상태 배지의 `solid / mid / warn / bad` 는 색 이름이 아니라 **강조 단계**입니다.

## 실행

```bash
npm start           # http://127.0.0.1:4173
npm run dev         # 파일 변경 시 자동 재시작
npm run smoke       # 백엔드 전 흐름 자동 검증 (158개 항목)
```

첫 실행 시 `backend/erp.db`(SQLite)가 `backend/data.json` 시드로 자동 생성됩니다.

## 업무 흐름

```
자재검색 → 구매요청 → 승인 → 발주서 → 입고 ─┬→ 재고 증가 (+수불 이력)
                                          ├→ 입고예정 차감
                                          └→ 매입전표 자동 기표

재고 → 공사 배정(가용재고 예약) → 현장 출고 → 공사별 원가·영수증

매출 등록 → 수금 → 수금전표 자동 기표 → 미수금 현황
```

**재고 수량은 한 곳에서만 바뀝니다.** `db.mjs`의 `moveStock()`이 유일한 쓰기 경로이며,
모든 변동은 `inventory_transactions`에 잔량과 함께 기록됩니다.
입고·이동·조정·출고는 SQLite 트랜잭션으로 묶여 부분 반영이 생기지 않습니다.

| 구분 | 의미 |
|---|---|
| 현재고 (on_hand) | 창고에 실제로 있는 수량 |
| 예약 (reserved) | 타 용도로 잡아둔 수량 |
| 배정 (allocated) | 특정 공사에 예약된 수량 |
| **가용 (available)** | `현재고 − 예약 − 배정` — 실제로 쓸 수 있는 수량 |
| 입고예정 (expected) | 승인된 발주의 미입고 수량 |

## 팀 공유 일정

**홈 > 작업 일정**에 월 달력이 하나 있습니다. 작업 일정과 휴가를 같은 달력에서 보고,
그 위에 공사 기간과(관리자에게만) 입찰 마감일을 겹쳐 얹습니다.

- 여러 날 걸친 일정은 칸마다 반복해 찍지 않고 **가로 막대 하나로 잇습니다.** 주를 넘어가면
  잘린 쪽 모서리를 평평하게 두어 이어진다는 것을 보여 줍니다.
- 한 주에 막대는 4줄까지 겹쳐 놓고, 넘치면 날짜 칸에 `＋N` 으로 접습니다.
- 위쪽 칩으로 종류별 표시를 켜고 끕니다. 날짜를 누르면 그날 일정이 아래에 펼쳐지고,
  빈 칸을 두 번 누르면 그 날짜로 등록창이 열립니다.

**누구 일정이든 서로 고칠 수 있습니다**(조회 전용 제외). 현장에서 서로 당겨주는 일이
흔해서 소유자 잠금을 두지 않았습니다. 대신 등록·수정·삭제가 전부 `audit_logs` 에 남고,
일정을 옮기면 `2026-10-05 → 2026-10-06` 처럼 이동 내역까지 기록됩니다.
휴가는 승인 절차 없이 바로 뜹니다.

## 권한 · 계정

### 역할

| 역할 | 업무 권한 | 금액 열람 |
|---|---|---|
| `admin` 관리자 | 전체 + 사용자·연동·회사정보 | **전부** |
| `purchasing` 구매 담당 | 기준정보, 공사, 구매요청/발주 승인, 팀 일정 | 품목 단가·발주 금액만 |
| `warehouse` 창고 담당 | 입고, 재고이동·조정, 공사 자재배정·출고, 팀 일정 | **없음** |
| `viewer` 조회 전용 | 모든 허용 화면 조회만 | **없음** |

### 금액은 두 단계로 나뉩니다

- **finance (관리자 전용)** — 경영 집계, 매출·수금, 회계 전표, 자금현황, 재고자산,
  공사 도급액·손익, 공급처 미지급금, 작업별 영수증
- **prices (관리자 + 구매 담당)** — 품목 단가, 발주 단가·금액, 구매요청 예상금액

### 관리자 전용 모듈

**회계 · 입찰 · 분석**은 모듈 통째로 관리자만 봅니다. 모듈바에서 사라질 뿐 아니라
`/api/bids*` 와 `/api/reports` 가 비관리자에게 **403** 을 돌려주므로, 주소창에
`#bid.calendar` 를 직접 쳐도 열리지 않습니다.

화면에서 감추는 것과 **별개로 서버가 응답에서 금액 필드를 지웁니다.**
`/api/sales-orders`, `/api/payments`, `/api/accounting-entries`, `/api/receipts/*` 는
비관리자에게 403 을 돌려주고, `/api/summary` · `/api/reports` · `/api/inventory` ·
`/api/purchase-orders` 는 금액 키 자체가 빠진 응답을 내보냅니다.
주소창으로 화면을 직접 열어도 권한이 없으면 열리지 않습니다.

### 계정 만들기

```bash
node backend/seed-users.mjs           # 기본 직원 계정 생성
node backend/seed-users.mjs --reset   # 이미 있으면 비밀번호만 재발급
```

비밀번호는 실행할 때 **한 번만** 출력됩니다. DB 에는 scrypt 해시만 남으므로
다시 확인할 수 없고, 잊으면 `--reset` 으로 새로 발급해야 합니다.
각자 로그인 후 **설정 > 비밀번호 변경**에서 바꾸게 하세요.

모든 쓰기 작업은 `audit_logs` 에 남아 **설정 > 변경이력**에서 확인할 수 있습니다.

## 나라장터 입찰공고 연동

**인증키가 없어도 화면은 그대로 동작합니다.** 샘플 공고 30건이 오늘 기준으로 분포되어
캘린더·목록·관심공고를 모두 시험해 볼 수 있고, 화면 상단 배너가 샘플 모드임을 알려줍니다.

### 실제 데이터로 전환

1. [공공데이터포털](https://www.data.go.kr/data/15129394/openapi.do)에서
   **조달청_나라장터 입찰공고정보서비스** 활용신청
2. 발급된 **일반 인증키(Decoding)** 를 `.env`에 추가
   ```
   G2B_SERVICE_KEY=발급받은키
   ```
3. 서버 재시작 → **설정 > 연동설정**에서 `나라장터 입찰공고`를 **사용**으로 전환
4. **입찰 > 입찰 캘린더**에서 `나라장터 동기화` 클릭

조회하는 오퍼레이션 (업무구분마다 엔드포인트가 다릅니다):

| 구분 | operation |
|---|---|
| 공사 | `getBidPblancListInfoCnstwk` |
| 물품 | `getBidPblancListInfoThng` |
| 용역 | `getBidPblancListInfoServc` |
| 외자 | `getBidPblancListInfoFrgcpt` |

가져온 공고는 `bid_notices`에 upsert되어 오프라인에서도 조회됩니다.
캘린더는 **공고일 / 마감일** 기준을 전환할 수 있고, 날짜를 클릭하면 그날 공고 목록이 열립니다.
`☆` 버튼으로 관심공고 등록, 상세창에서 검토 메모를 남길 수 있습니다.

> 인증키는 서버 프로세스 환경변수로만 읽습니다. DB·응답·브라우저 어디에도 저장하지 않습니다.
> 포털이 주는 Encoding/Decoding 두 키 중 어느 쪽을 넣어도 이중 인코딩되지 않도록 처리합니다.

```
frontend/
  index.html   셸 (로그인 + 앱 프레임)
  styles.css   디자인 시스템 (토큰·그리드·KPI·차트·모달)
```

화면은 선언형으로 정의합니다. `dataScreen({ filters, load, columns, rowActions })`가
조회·정렬·합계·엑셀·행 버튼을 자동으로 붙이고, `masterScreen({...})`은 여기에
등록/수정/삭제 모달까지 얹습니다. 새 업무 화면 추가는 보통 설정 객체 하나면 됩니다.

## 알려진 제약

- 세션은 서버 메모리에 있어 **재시작하면 전원 로그아웃**됩니다.
- 발주는 1건당 1품목입니다(다품목 발주서 미지원).
- 가격비교 소스 중 **인증키 없이 도는 것은 자재몰 수집 하나뿐**입니다. 네이버·쿠팡·알리·나라장터는
  각자 키가 필요하고, 키가 없으면 화면이 그 이유를 그대로 안내합니다.
- 자재코리아는 상품의 **약 2%만 가격을 공개**합니다(나머지는 `전화문의`). 그래서 이 소스는
  가격이 아니라 품목·규격을 채우는 데 씁니다.
- 쿠팡·알리 어댑터는 서명까지 구현했지만 키가 없어 **실제 응답으로 검증하지 못했습니다.**
  각각 `probe` 엔드포인트로 필드명을 확인한 뒤 매핑을 고치는 구조입니다.
- LS산전은 가격을 싣지 않고 사이트가 클라이언트 렌더링이라 자동 수집이 불가합니다.
  대리점 가격표를 CSV 로 올리는 경로를 씁니다. → `backend/CONNECTORS.md`
- CSV/SFTP 정기 수집과 제조사 카탈로그 어댑터는 아직 없습니다.
- `node:sqlite`는 Node 22에서 experimental이라 `--no-warnings`로 실행합니다.
